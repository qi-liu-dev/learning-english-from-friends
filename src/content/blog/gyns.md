---
title: "Gyns, Guys and the Words We Use for a Group"
description: "why I've never liked using 'guys' for everyone."
pubDate: "Oct 23 2026"
---

I've never felt comfortable using guys to address a group that includes women.

I know that many English speakers use guys as if it were gender-neutral, especially in expressions like *you guys*. But it has never sounded neutral to me. *Guy* literally means a man, so using the male word to represent everyone has always felt strange.

A few years ago, I also had workplace training that encouraged us to use expressions like **"Hi all," "everyone,"** or **"Hi team"** instead. That made perfect sense to me, and I've used those alternatives ever since.

Today, though, I heard something new.

In a chat group, someone addressed everyone as **gyns**.

I'd never seen the word used like that before, so I looked it up. The root **gyn-** comes from Greek and means **woman** or **female**, the same root you see in words like *gynecology*.

So *gyns* seems to be a playful female counterpart to *guys*.

It's definitely not a standard everyday English word, and I wouldn't expect everyone to immediately know what it means. But I still found the idea interesting.

If “guys” can become a casual way to address a whole group, maybe women can start making “gyns” a thing too.
