# Learning English from Friends

A personal journal about the English words, expressions, mistakes, and small discoveries I encounter in everyday life.

The project was inspired by CMU Associate Teaching Professor Terry E. Lee's *Learn English from Friends* and the idea that language can be learned not only from textbooks, but also from conversations, experiences, and the people around us.

## Website

[Visit Learning English from Friends](https://qi-liu-dev.github.io/learning-english-from-friends/)

## About the Project

I have lived abroad for many years and am currently based in the Netherlands. Although English is part of my daily life, I still learn something new almost every day.

This blog is where I collect those moments and explore how English is used in real situations.
